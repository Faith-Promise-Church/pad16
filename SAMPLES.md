# Samples

## File names

A folder under `kits/` is a kit. The file name sets everything about a pad.

| In the name | Meaning | Example |
| --- | --- | --- |
| A leading number 1 to 16 | Which pad | `5 Snare.wav` |
| `[loop]` or `[hold]` | Play mode (default is one shot) | `12 Swell [hold].wav` |
| `[92bpm]` or `92bpm` | The loop's own tempo | `9 Groove [loop] [92bpm].wav` |
| `[4bars]` or `4bars` | The loop's length | `9 Groove [loop] [92bpm] [4bars].wav` |
| `[group:a]` (a to d) | Exclusive group | `10 Shaker [loop] [group:a].wav` |

- Files without a number fill the free pads in alphabetical order.
- A kit can hold more than 16 files. The extras do not get a pad, but pattern tracks can use them.
- A loop with no tempo tag is measured when it loads: first by assuming it is a whole number of bars (1, 2, 4, 8 or 16, preferring 70 to 140 BPM), then cross-checked against its onsets. Edit view shows the confidence, and you can type a tempo, press x2 or /2, or set the bar count.
- Formats: anything the browser decodes. WAV, MP3, M4A/AAC, AIFF and CAF all work on iPad. WAV is safest for loops.

The starter patterns are written against slot names (Stomp, Clap, Cajon Bass and so on). When the Acoustic Set has a file with that name, the pattern plays that file, so replacing a stand-in also upgrades every pattern that uses it.

Stand-ins come from `scripts/make-acoustic-kit.mjs`, which fills empty slots only and never overwrites a file. The files marked Justin were supplied by him and published at his direction; the stand-ins are generated by code in this repo.

## Click sets

A folder under `kits/` whose audio files are all named `Click Accent.wav` (beat 1), `Click Beat.wav` and `Click Sub.wav` (subdivisions) is a click set. It appears in the Click settings as a choice beside Built-in. A set that is missing one of the three uses the built-in sound for that one.

`kits/Justin Click/` was chopped from `Click Loop 80bpm.wav`, a bar of eighth notes: hit 1 is the accent, hit 3 the beat, hit 2 the off-beat used for subdivisions. Each is trimmed to its own tail and leveled; the Accent, Beat and Subdivision levels in the app set the balance.

## Replacing a stand-in with a real recording

1. Record the sound (see the guide below) and save it anywhere, named for its slot: `1 Stomp.wav`, `7 Clap.m4a` and so on. You only need the files you are replacing.
2. Put the new recordings in one folder together with copies of the stand-ins you want to keep (copy them out of `kits/Acoustic Set/`).
3. Run the prep script (needs ffmpeg: `brew install ffmpeg`):

   ```
   node scripts/prepare-kit.mjs ~/Desktop/acoustic-takes "Acoustic Set" --replace
   ```

   It converts everything to 48 kHz 16-bit WAV, trims silence before each hit and after each tail, leaves `[loop]` files untrimmed so the seam stays exact, matches levels to -1 dB peak, keeps the tempo, bar and group tags, and rebuilds `kits/index.json`. Options: `--mono` (half the memory), `--peak -3`, `--no-normalize`, `--no-trim`.
4. `git add kits && git commit -m "Real stomps and claps" && git push`. The kit updates on the next deploy.

To replace one sound without the script, drop a 48 kHz WAV with the same file name into `kits/Acoustic Set/` and push.

## Pad sets for the tonic pad

A folder under `kits/` whose audio files are all named by key is a pad set: `Pad C.wav`, `Pad Db.wav`, `Pad D.wav` through `Pad B.wav` (sharps work too: `Pad C#.wav`). Several pad sets can sit side by side; pick one in the tonic pad settings.

Prepare a set from raw recordings with pad mode:

```
node scripts/prepare-kit.mjs ~/Desktop/pads "Warm Pads" --pad --length 20 --fade 2
```

Each file is trimmed to the length and gets an equal-power crossfade baked into the loop point, so it loops with no click. The output is named `Pad C [baked].wav`; the tag tells the app the crossfade is already there. A file without the tag gets its crossfade when it loads.

If a set is missing a key, the app plays the nearest key it has, pitch-shifted, and labels that as a fallback.

Two sets are in the repo, both in all 12 major keys as one-minute 320 kbps MP3s, untouched apart from their names: `kits/Mesosphere (shimmery)/` and `kits/Troposphere (mellow)/`. MP3s carry a few milliseconds of padding, so they are left untagged and the app bakes the loop crossfade when each one loads; a browser test checks the seam. The minor and neutral versions were left out.

In the web app, every key of the selected pad set is saved for offline use in the background the first time the app is open online (about 37 MB per set). The tonic pad settings show the progress. The iOS app has the files inside it.

The app decodes pads only when needed and keeps at most three in memory: the current key, the previous one, and the next song's key.

## Recording guide: stomps, claps and snaps on a phone

- **Use the Voice Memos app set to Lossless** (Settings, Apps, Voice Memos, Audio Quality), or any recorder that saves WAV.
- **Room**: a carpeted room with soft furniture. Hard, empty rooms add a ring you cannot remove.
- **Distance**: 1 to 1.5 m from the sound. Closer than that the phone's limiter squashes the hit; further away you record the room.
- **Stomps**: put the phone on a cushion on the floor (so it does not rattle), about a metre from your foot. Stomp on a wooden floor or a plywood board in a hard-soled shoe. Record ten and keep the best.
- **Group stomps and claps**: three or four people, a little loose on purpose. Or layer your own takes: record five single hits, then stack them in any editor with 10 to 30 ms between them.
- **Claps**: cup the hands slightly for a rounder sound, flat hands for a sharper one. Clap past the microphone, not straight at it.
- **Snaps**: closer, about 40 cm, and off to one side.
- **Cajon and djembe**: the phone 50 cm in front for slaps; for the bass tone, aim it at the sound hole from 30 cm, slightly off axis so the air does not hit the microphone.
- **Tambourine and shaker**: 1 m away. For shaker elements record single forward and back strokes; for a loop, play to a click at a known tempo, cut exactly on bar lines, and name it with the tempo and length: `14 Shaker Loop [loop] [96bpm] [2bars].wav`.
- **Levels**: leave silence before and after each hit. Do not worry about level: the prep script trims and normalizes.
- **Check**: load the kit, play each pad next to the stand-in it replaced, and listen on the PA, not on the iPad speaker.
